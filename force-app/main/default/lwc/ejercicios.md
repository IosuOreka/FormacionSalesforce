1. Componente "Hola Mundo"
Descripción: Crea un componente LWC que muestre un texto estático que diga "Hola Mundo" en la pantalla.
Objetivo: Familiarizarse con la estructura básica de LWC (HTML, JavaScript, CSS).
2. Propiedades y Atributos
Descripción: Crea un componente que reciba un texto como propiedad (@api) y lo muestre en la pantalla.
Objetivo: Entender cómo funcionan las propiedades públicas (@api) y cómo interactuar con ellas.
3. Eventos Básicos
Descripción: Crea un componente con un botón que, al hacer clic, cambie el texto mostrado en la pantalla.
Objetivo: Trabajar con eventos básicos, como onclick, y manejar el estado interno de un componente.
4. Componente de Lista Simple
Descripción: Crea un componente que reciba una lista de elementos (nombres) y los muestre en una lista ordenada.
Objetivo: Utilizar listas (for:each) y entender la creación dinámica de elementos en LWC.
5. Formulario Simple con Validación
Descripción: Crea un formulario con campos de texto (nombre, email) y un botón de envío. Valida que todos los campos estén llenos antes de permitir el envío.
Objetivo: Manejar formularios y aplicar validaciones simples en JavaScript.
6. Componente Hijo-Padre (Comunicación entre Componentes)
Descripción: Crea dos componentes, uno padre y otro hijo. El componente hijo debe enviar un evento al padre cuando se haga clic en un botón, y el padre debe mostrar un mensaje en respuesta.
Objetivo: Aprender la comunicación entre componentes usando eventos personalizados (CustomEvent).
7. Consulta Simple con Apex
Descripción: Crea un componente que recupere registros de un objeto de Salesforce (como Account o Contact) usando Apex y los muestre en una tabla.
Objetivo: Integrar Apex con LWC, entender cómo hacer llamadas a métodos del servidor desde LWC.
8. Componente de Búsqueda con Apex
Descripción: Crea un componente que permita buscar registros por nombre (por ejemplo, buscar Account por nombre) usando un campo de entrada y mostrando resultados en tiempo real.
Objetivo: Aprender a manejar inputs en LWC, hacer búsquedas en tiempo real, y usar promesas para manejar respuestas asíncronas.
9. Uso del LDS (Lightning Data Service)
Descripción: Crea un componente que muestre los detalles de un registro de Account usando LDS en lugar de Apex.
Objetivo: Usar el Lightning Data Service para obtener y modificar registros sin necesidad de Apex.
10. Componente de Modal (Diálogo Emergente)
Descripción: Crea un componente que tenga un botón que, al hacer clic, abra un modal con un formulario simple.
Objetivo: Aprender a manejar modales, aplicar estilos en LWC y manejar el estado para mostrar/ocultar elementos.
11. Data Table con Operaciones CRUD (Create, Read, Update, Delete)
Descripción: Crea un componente que muestre una tabla de registros (ej. Contact) y permita editar, eliminar y crear nuevos registros usando un formulario.
Objetivo: Entender las operaciones CRUD completas en LWC usando Apex.
12. Componente de Filtrado Dinámico
Descripción: Crea un componente que permita filtrar registros de Account por varios criterios (nombre, industria, etc.) y actualice la lista de resultados dinámicamente.
Objetivo: Aprender a manejar múltiples filtros y actualizaciones en tiempo real.
13. Drag and Drop en LWC
Descripción: Crea un componente de lista que permita arrastrar y soltar elementos para reordenarlos.
Objetivo: Usar eventos del navegador para implementar funcionalidad de arrastrar y soltar (drag y drop), manejar el DOM en LWC.
14. Componente de Gráfico usando D3.js o Chart.js
Descripción: Crea un componente que muestre datos en forma de gráfico (ej. gráfico de barras o pastel) utilizando una librería externa como D3.js o Chart.js.
Objetivo: Integrar bibliotecas externas en LWC y entender cómo interactuar con ellas.
15. Paginar una Lista de Registros
Descripción: Crea un componente que muestre registros en una tabla con paginación (ej. mostrar 10 registros por página y permitir avanzar/retroceder).
Objetivo: Manejar la lógica de paginación en LWC, trabajar con componentes más complejos.
16. Componente de Chat en Tiempo Real usando Salesforce Streaming API
Descripción: Crea un componente de chat en tiempo real que use la API de streaming de Salesforce para actualizar mensajes en tiempo real.
Objetivo: Trabajar con APIs en tiempo real en LWC y entender la suscripción a eventos de la plataforma.
17. Componente de Dashboard Personalizado
Descripción: Crea un componente que muestre métricas clave en un tablero (dashboard) usando gráficos, tarjetas y estadísticas. Integra datos en tiempo real si es posible.
Objetivo: Integrar múltiples componentes en un solo tablero, manejar datos dinámicos, y aplicar conceptos avanzados de diseño en LWC.
18. Aplicación Completa con Navegación (SPA)
Descripción: Crea una aplicación LWC que tenga múltiples "páginas" (ej. Home, Contactos, Cuentas) y permita navegar entre ellas sin recargar la página.
Objetivo: Construir una Single Page Application (SPA) en LWC, manejar rutas y estados complejos en la interfaz.
19. Integración con API Externa REST
Descripción: Crea un componente que haga una llamada a una API externa (no Salesforce) para recuperar datos y mostrarlos en una tabla.
Objetivo: Aprender a trabajar con APIs externas desde LWC usando fetch o XMLHttpRequest.
20. Aplicación de Gestión de Casos con Seguridad Avanzada
Descripción: Crea una aplicación que gestione casos (tickets) en Salesforce, permita su creación, asignación y cambio de estado. Incluye controles de acceso según el perfil del usuario.
Objetivo: Integrar la lógica de negocio, seguridad, LDS, y Apex avanzado en un solo proyecto completo.
